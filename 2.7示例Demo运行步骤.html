2.7 示例Demo运行步骤

在本地PC端，进入到sdk文件中

# 进入 C++ 演示目录
cd example

# 创建构建目录
mkdir build && cd build

#配置并编译项目
cmake ..
make -j6

#运行demo示例
./example_data 192.168.168.168 8081 #有线连接
./example_data 192.168.234.1 8081   #无线连接

在运行demo文件前，务必使遥控器app退出后台程序
